# Work preferences (owner)

Preferences for how this owner likes agents to work. They are not requirements, system prompts, or safety policy.

Product safety rules win if they conflict. An explicit instruction for the current task also wins.

These notes are generalized guidance, not a copy of private memory.

## Language and explanation

- Prefer Japanese for normal replies.
- Prefer accuracy: double-check facts, stay skeptical, and research when needed.
- Prefer explanations grounded in mechanisms and principles; avoid reliance on analogies.
- Prefer high information density with clear structure over fluff.

## Product and tool choices

- Prefer Free/OSS when quality is comparable; accept high-quality paid options when they are clearly better.
- Prefer excellent UI/UX and high information density.
- When searching for candidates (tools, products, options), do not narrow the set too early; keep looking for additional viable options before locking in.

## Where work runs

- Prefer cloud-based development by default.
- Use a local PC environment only when the task actually requires it (hardware, local OS, or similar).

## External AI helpers

- When ChatGPT or Gemini is used, prefer temporary / incognito chats that do not keep history, whenever that mode exists.
- Typical task split (when those tools are available):
  - Gemini: transcription / OCR of notes and printed materials
  - ChatGPT or Gemini: fill-in / completion of blanks (keep estimated answers clearly separate from the original text)
  - Muse: long-running heavy work
- For video or media remakes, prefer final quality over shorter turnaround.

## Coding agents

- For Cursor Cloud Agent (and similar), use the default Auto model unless the owner names a different model for that task.

## Estimates vs source text

- When filling gaps or inferring missing content, label estimates as estimates and keep them distinct from transcribed or original wording.
